PC-12 FUEL APP — INSTALLATION

This is a Progressive Web App (PWA).

To install it on an iPhone:
1. Upload the contents of this folder to a simple HTTPS web host.
2. Open the resulting web address in Safari.
3. Tap Safari's Share button (square with upward arrow).
4. Tap "Add to Home Screen".
5. Open PC-12 Fuel from the Home Screen.
6. After the first load, the service worker caches the app for offline use.

FILES:
- index.html — calculator
- manifest.webmanifest — app metadata
- service-worker.js — offline cache
