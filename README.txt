KEW FUEL QUICK CHECK

Purpose
- Personal cockpit companion to Air Trail.
- Does not duplicate Air Trail flight logging, passenger entry, W&B sign-off, times, duty, or signatures.

Included
1. Halfway / enroute fuel check
2. Landing weight / maximum landing fuel check
3. Round-trip fuel check
4. Quick-reference tab

Current saved company figures
- Taxi: 44 lb
- Reserve: 413 lb

Install
Upload index.html, manifest.json and sw.js to the same GitHub Pages repository/folder. Open the Pages URL on iPhone, then use Safari Share > Add to Home Screen.

IMPORTANT
This is a personal quick-reference aid only. Verify all operational numbers and formulas against current Keewatin approved manuals, Air Trail, AFM/POH, QRH and company procedures.
